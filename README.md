## Overview

TemperaMental is a Windows and macOS application for composing and playing back animated emitter patterns on the [Beetlecrab Tempera](https://beetlecrab.audio) granular synthesiser via MIDI CC. Draw emitters onto a virtual grid and watch them appear on the hardware in real time. Build up sequences of frames and play them back through the built-in sequencer, or generate evolving patterns live using the transform tools and capture them as you go.

---

## Features

- **Real-time control** — place and remove emitters on the Tempera instantly via MIDI CC
- **Transform tools** — shift, rotate, flip, swap and randomise emitter patterns on the grid; latch a direction to animate continuously in sync with the current BPM
- **Sequencer** — play back sequences of frames with loop, reverse and seek support; BPM adjustable on the fly
- **Recording** — capture transform output directly into a sequence, frame by frame
- **MIDI file support** — save and load sequences as standard `.mid` files

---

## Getting Started

1. Download and extract the Windows or macOS release [here](https://github.com/ezoray/temperamental/releases/latest)
2. Connect the Tempera via USB
3. Run the executable, the Tempera should be detected automatically
4. Draw on the grid with the mouse; emitters will appear on the hardware in real time

For everything else, the user guide included with the release covers the app in full detail.
